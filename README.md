# Smart Home Project

Учебный проект по дисциплинам **ПОИС** и **ООП**: консольное приложение
для управления устройствами «умного дома».

## О проекте

Приложение позволяет управлять несколькими типами устройств,
настраивать таймеры их работы и просматривать состояние системы.

На данном этапе устройства **симулированы** — реальное подключение
к железу не реализовано, но архитектура заложена так, чтобы его
можно было добавить позже.

## Возможности

### Устройства

| Устройство | Функционал |
|---|---|
| 💡 Умная лампа | включение/выключение, регулировка яркости |
| ❄️ Кондиционер | включение/выключение, режим (тепло/холод), целевая температура |
| 🔌 Умная зарядка | включение/выключение, вывод данных (мощность, напряжение, ток, заряд) |
| 🤖 Робот-пылесос | включение/выключение, возврат на базу, очистка бака |

### Таймеры

- Разовые: «включить лампу в 19:00»
- Интервальные: «работать с 9:00 до 18:00»

### Управление

- Консольный интерфейс
- Просмотр состояния всех устройств
- Ручное управление каждым устройством
- Управление таймерами

## Технологии

- **Язык:** C++17
- **Сборка:** CMake
- **Тесты:** GoogleTest *(планируется)*
- **Форматирование:** clang-format
- **CI:** GitHub Actions *(планируется)*

## Архитектура

Проект построен на принципах ООП и SOLID.

### Основные классы

Device (абстрактный)
 ├── Lamp
 ├── AirConditioner
 ├── SmartCharger
 └── VacuumRobot

Timer (абстрактный)
 ├── OneShotTimer
 └── IntervalTimer

SmartHome — хранит устройства и таймеры, координирует их работу
CommandParser — разбирает команды пользователя
ConsoleUI — консольный интерфейс

### Принципы

- **Инкапсуляция** — состояние устройств скрыто, доступ через методы
- **Наследование** — общие свойства устройств вынесены в базовый `Device`
- **Полиморфизм** — устройства хранятся как `std::unique_ptr<Device>`
- **SOLID** — `SmartHome` не делает работу сам, а координирует устройства
