# Smart Home Project

Учебный проект по дисциплинам **ПОИС** и **ООП**: консольное приложение
для управления устройствами «умного дома».

## О проекте

Приложение позволяет управлять несколькими типами устройств,
настраивать таймеры их работы и просматривать состояние системы.

На данном этапе устройства **симулированы** — реальное подключение
к железу не реализовано, но архитектура заложена так, чтобы его
можно было добавить позже.

## Возможности

### Устройства

| Устройство | Функционал |
|---|---|
| 💡 Умная лампа | включение/выключение, регулировка яркости |
| ❄️ Кондиционер | включение/выключение, режим (тепло/холод), целевая температура |
| 🔌 Умная зарядка | включение/выключение, вывод данных (мощность, напряжение, ток, заряд) |
| 🤖 Робот-пылесос | включение/выключение, возврат на базу, очистка бака |

### Таймеры

- Разовые: «включить лампу в 19:00»
- Интервальные: «работать с 9:00 до 18:00»

### Управление

- Консольный интерфейс
- Просмотр состояния всех устройств
- Ручное управление каждым устройством
- Управление таймерами

## Технологии

## Архитектура

Проект построен на принципах ООП и SOLID.

### Основные классы

Device (абстрактный)
 ├── Lamp
 ├── AirConditioner
 ├── SmartCharger
 └── VacuumRobot

Timer (абстрактный)
 ├── OneShotTimer
 └── IntervalTimer

SmartHome — хранит устройства и таймеры, координирует их работу
CommandParser — разбирает команды пользователя
ConsoleUI — консольный интерфейс

### Принципы

- **Инкапсуляция** — состояние устройств скрыто, доступ через методы
- **Наследование** — общие свойства устройств вынесены в базовый `Device`
- **Полиморфизм** — устройства хранятся как `std::unique_ptr<Device>`
- **SOLID** — `SmartHome` не делает работу сам, а координирует устройства

## Структура проекта

- `include/`, `src/`, `apps/` — C++ ядро устройств, эмуляторы и микро-приложения MQTT
- `gateway/` — FastAPI-шлюз (REST API + WebSocket + чтение SQLite и `data/rules.json`)
- `gui/` — десктопный клиент на Qt 6 (`SmartHomeGui`)
- `tests/` — модульные тесты ядра (GoogleTest) и GUI (`QtTest`)

## Сборка и запуск Qt 6 GUI-клиента (`SmartHomeGui`)

### Требования

- Qt 6 (модули `Widgets`, `Network`, `WebSockets`, `Charts`, `Test`)
- CMake ≥ 3.16, Ninja / MinGW (или совместимый C++17 компилятор)
- Запущенный брокер Mosquitto (`localhost:1883`) и FastAPI-шлюз (`http://127.0.0.1:8001`)

### Сборка только GUI (Windows, Qt MinGW)

```powershell
cmake -S . -B build-gui -G Ninja `
  -DCMAKE_PREFIX_PATH="E:/Qt/6.12.1/mingw_64" `
  -DBUILD_BACKEND=OFF -DBUILD_GUI=ON -DBUILD_GUI_TESTS=ON
cmake --build build-gui
```

### Запуск тестов GUI

```powershell
ctest --test-dir build-gui --output-on-failure
```

### Запуск стенда целиком (Mosquitto + Gateway + Эмуляторы + Qt GUI)

1. Убедитесь, что служба `mosquitto` запущена (`localhost:1883`).
2. Запустите FastAPI-шлюз (в виртуальном окружении с зависимостями из `gateway/requirements.txt`):

   ```powershell
   uvicorn gateway.main:app --host 127.0.0.1 --port 8001
   ```

3. Запустите нужные C++ микро-приложения устройств из `build/` (`app_lamp.exe`, `app_plug.exe`, `app_radiator.exe`, `app_thermostat.exe`, `app_hygrometer.exe`).
4. При необходимости разверните Qt DLL рядом с `.exe` (`windeployqt build-gui\gui\SmartHomeGui.exe`) и запустите `build-gui\gui\SmartHomeGui.exe`.
